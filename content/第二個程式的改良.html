第二個程式的改良

以下是第二個程式的原始碼分析:

一、整體架構總覽

這是一個：Flask 網頁 + Brython 寫的點擊小遊戲 + Ajax 上傳分數

📌 技術角色分工：

技術 用途
Flask 後端伺服器、分數儲存
Jinja2 HTML 模板引擎
Brython 在瀏覽器執行 Python
JavaScript (Ajax) 非同步送分數
HTML / CSS 遊戲畫面


二、Jinja2 模板結構說明

{% extends "base.html" %}

🔹 繼承 base.html

使用 Flask 常見的 模板繼承

base.html 通常包含：

<html>

<head>

導覽列

共用 CSS
{% block title %}Brython 遊戲{% endblock %}
🔹 設定頁面標題
對應 base.html 裡的 {% block title %}

瀏覽器標題顯示「Brython 遊戲」


{% block content %} ... {% endblock %}
🔹 主內容區
整個遊戲畫面都在這個區塊內

三、載入 Brython

<script src="https://cdn.jsdelivr.net/npm/brython@3.11.3/brython.min.js"></script> <script src="https://cdn.jsdelivr.net/npm/brython@3.11.3/brython_stdlib.js"></script>
🔹 這兩個做什麼？
檔案 功能
brython.min.js Brython 核心
brython_stdlib.js Python 標準函式庫
📌 沒有它們，瀏覽器看不懂 <script type="text/python">


<body onload="brython(1)">
🔹 啟動 Brython
網頁載入完成 → 啟動 Brython

1 代表「debug 模式」

四、遊戲畫面 HTML

<h2 style="text-align: center;">🕹️ 點擊測試：點擊移動中的圓形！</h2>
➡️ 遊戲標題


<div id="brython_div1" style="width: 600px; height: 400px; margin: 20px auto;"></div>
🔹 遊戲場地
寬：600px

高：400px

所有遊戲元素都動態加到這裡

五、為什麼要用 {% raw %}？

{% raw %} <script type="text/python">
🔹 解決的問題
Brython 裡有：

f"{score}"

{}

⚠️ Jinja2 會誤以為是模板語法

➡️ {% raw %} 告訴 Jinja2：「這一段我不解析，原封不動交給瀏覽器」

六、Brython：匯入模組

from browser import document, timer, window, ajax import random import time
🔹 每個模組用途
模組 功能
document 操作 DOM
timer setTimeout / setInterval
window JS 的 window
ajax Ajax 請求
random 隨機位置、顏色
time 計時


七、遊戲全域設定

GAME_DURATION = 30 score = 0 game_active = False
變數 說明
GAME_DURATION 遊戲時間（秒）
score 玩家分數
game_active 是否進行中


八、初始化遊戲區（DOM 操作）

game_area = document["brython_div1"]
➡️ 抓取 <div id="brython_div1">


game_area.style.border = "3px solid #333" game_area.style.backgroundColor = "#e0e0ff" game_area.style.position = "relative"

🔹 為什麼要 position: relative？

👉 讓裡面的圓形可以用 absolute 定位

九、分數與時間顯示區

score_display = document.createElement("div") timer_display = document.createElement("div")
左上角：分數

右上角：倒數時間

📌 這些都是 動態建立的 DOM 元素

十、目標圓形（遊戲核心）

target = document.createElement("div") target.style.width = "50px" target.style.height = "50px" target.style.borderRadius = "50%"
➡️ 一個 50×50 的圓形


target.style.transition = "top 0.3s, left 0.3s"
➡️ 平滑移動動畫

十一、移動圓形

def move_target():
🔹 功能流程
檢查遊戲是否進行中

計算最大可移動範圍

隨機產生新位置

隨機顏色

更新 top / left

📌 min_y = 40
→ 避免蓋住上方分數欄

十二、點擊事件

@target.bind("click") def hit_target(event):
🔹 這裡很重要！
只有點到圓形才會觸發

不用額外計算距離

流程：

分數 +1

更新顯示

圓形立即移動

stopPropagation() 防止事件冒泡

十三、Ajax 上傳分數（Brython → Flask）

req.open('POST', '{{ url_for("submit_score") }}', True)

🔹 為什麼要 {% endraw %}？

url_for() 必須由 Jinja2 處理

Brython 不認得 Flask

👉 這是 Flask + Brython 混用的標準寫法


json_payload = window.JSON.stringify({'score': final_score}) req.send(json_payload)
➡️ 送出 JSON：


{ "score": 15 }
