Brython 是什麼？如何在瀏覽器配置 Brython 環境？ Brython 能做什麼？

一、Brython 是什麼？

Brython = Browser Python（瀏覽器中的 Python）

👉 它是一個 JavaScript 函式庫，讓你可以：

在 瀏覽器裡直接寫 Python

用 Python 操作 HTML / CSS / DOM

不用後端、不用安裝 Python

開啟網頁就能跑

📌 本質：

Python 語法

在瀏覽器中 轉成 JavaScript 執行

為什麼會有 Brython？

因為：

瀏覽器只懂 JavaScript

但很多人更熟 Python

Brython 幫你把 Python「翻譯」成瀏覽器能跑的程式

Brython 跟其他東西的比較
技術 在哪跑 用途
Python 電腦 / 伺服器 後端、資料分析
JavaScript 瀏覽器 網頁互動
Brython 瀏覽器 用 Python 寫前端
Flask / Django 伺服器 網站後端

📌 Brython 是前端，不是後端

如何在瀏覽器配置 Brython 環境
✅ 最簡單（只要一個 HTML）
<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>Brython Demo</title>

<!-- 載入 Brython -->
<script src="https://cdn.jsdelivr.net/npm/brython@3.11.3/brython.min.js"></script>
</head>

<body onload="brython()">

<h1 id="title">Hello</h1>

<script type="text/python">
from browser import document

document["title"].text = "Hello Brython!"
</script>

</body>
</html>


📌 重點只有 4 個：

1️⃣ 載入 brython.min.js
2️⃣ <body onload="brython()">
3️⃣ <script type="text/python">
4️⃣ from browser import document

打開這個 HTML，不用伺服器，直接能跑

✅ 進階：外部 Python 檔案
<script type="text/python" src="main.py"></script>

# main.py
from browser import document

document <= "Brython is cool!"


📌 非常適合：

遊戲

專案結構化

GitHub Pages

Brython 能做什麼？
1️⃣ 操作網頁（DOM）
from browser import document

document["btn"].bind("click", lambda e: alert("Clicked!"))


你可以：

改文字

改顏色

處理按鈕事件

2️⃣ 取代 JavaScript（用 Python 寫前端）
JavaScript Brython
document.getElementById() document["id"]
addEventListener bind()
innerHTML .html

📌 非常適合「會 Python、不想寫 JS」的人

3️⃣ 做遊戲（你最近在做的）

Brython 很適合：

🎯 Aim Lab 類型遊戲

🟦 點擊反應遊戲

🕹 Canvas 遊戲

🧪 教學用互動模擬

你已經用到的功能包括：

計時器

滑鼠事件

隨機生成目標

計分系統

4️⃣ 教學與作業展示（GitHub Pages）

📌 很多老師喜歡 Brython，因為：

不用安裝環境

一個 HTML 就能交

GitHub Pages 直接展示

適合「程式 + 說明」

5️⃣ 學習前端邏輯（不被 JS 卡住）

Brython 讓你專注在：

事件

狀態

邏輯

遊戲設計

而不是 JS 語法細節

Brython 的限制

⚠️ Brython 不是萬能

❌ 不適合

後端伺服器

資料庫

高效能大型遊戲

AI / ML 運算

⚠️ 注意

效能 < 原生 JavaScript

部分 Python 套件不能用

依賴 CDN（離線需額外設定）

什麼情況「非常適合」用 Brython？

✅ 你是 Python 使用者
✅ 想做 網頁互動 / 小遊戲
✅ 要交作業、展示成果
✅ 用 GitHub Pages
✅ 教學、Demo、Prototype

➡️ Brython = 最佳選擇

總結:

Brython 就是：用 Python 在瀏覽器寫前端程式
